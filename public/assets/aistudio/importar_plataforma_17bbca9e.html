📤 ¿Cómo exportar desde {{ platform }}?

{% if platform == "SAP" %}
  1. Ejecuta la transacción SU01 o el reporte RSUSR002
  2. Filtra los usuarios activos de tu mandante
  3. Exporta con Ctrl+Shift+F7 → Guardar → Hoja de cálculo
  4. Columnas clave para el cruce: nombre, email o rut
{% elif platform == "Salesforce" %}
  1. Ve a Configuración → Usuarios → Usuarios
  2. Clic en "Exportar a Excel" en la lista
  3. O crea un Informe de Usuarios con: Nombre, Email, Perfil, Estado
  4. El campo email es el más preciso para el cruce
{% elif platform == "Office 365" %}
  1. Accede al Centro de administración de Microsoft 365
  2. Ve a Usuarios → Usuarios activos
  3. Clic en "Exportar usuarios" (arriba a la derecha)
  4. El CSV incluye Display name y User principal name (email)
{% elif platform == "HCM" %}
  1. Accede al módulo de administración de tu HCM
  2. Ve al listado de empleados activos
  3. Exporta en Excel incluyendo: RUT, nombre, email, departamento, cargo
  4. El RUT y el email son los mejores campos para el cruce automático
{% elif platform == "ERP Propio" %}
  1. Accede al panel de administración de tu ERP
  2. Ve a Usuarios del sistema
  3. Exporta en Excel o CSV incluyendo: usuario, nombre, email, RUT
{% elif platform == "Portal Clientes" %}
  1. Accede al panel de administración del portal
  2. Ve a Gestión de usuarios
  3. Exporta el listado con: email, nombre, empresa, estado
{% else %}

Exporta el listado de usuarios desde el panel de administración de {{ platform }} en formato Excel (.xlsx) o CSV. Incluye siempre las columnas email y/o RUT para maximizar el cruce automático.
