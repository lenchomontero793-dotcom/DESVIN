{% if ai_key_env %}Se está usando la variable de entorno ANTHROPIC_API_KEY.{% endif %}
La API key se crea en la consola de Anthropic (console.anthropic.com → Settings). Es distinta de una suscripción a Claude.ai y se factura aparte, por uso. Se guarda solo en data/config.json de este equipo; nunca se muestra de nuevo ni se incluye en los respaldos.
Instala Ollama (ollama.com) y descarga un modelo, por ejemplo ollama pull llama3.1. Los modelos pequeños a veces no siguen bien el formato de propuestas; si ves respuestas sin cambios aplicables, prueba un modelo más grande.
🔒 Qué se envía al proveedor: solo parámetros del sistema (configuración del servicio, nombre/tipo/estado de las plataformas, mapeos de campos, roles y permisos, y conteos agregados del cruce) más tu conversación.
Nunca se envía: usuarios, RUT, correos, contraseñas, tokens, URLs de API ni claves. Con Ollama nada sale de tu red.
Qué no puede hacer: modificar código, credenciales ni URLs, ver datos de personas, borrar plataformas o roles, ni reiniciar el servicio.
